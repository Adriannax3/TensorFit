# TensorFit
Web application for monitoring physical activity using artificial intelligence

# Project description

The project's goal was to create an app for tracking physical activity using a camera. Camera images are processed using artificial intelligence to count repetitions of simple exercises. Users have access to their workout history, presented in the form of graphs. Additionally, the app offers social features, such as sharing results and participating in leaderboards.

# Stack
- React
- Vite
- Node
- Express
- PostgreSQL
- Sequelize
- TensorFlow
- AntDesing
